Deep Dive: b:tag, b:attr, and b:class (Dynamic HTML)

Sometimes you need your HTML tags to be dynamic—for example, changing an <h1> to an <h2> based on the page type. Blogger provides b:tag, b:attr, and b:class for exactly this purpose.

1. The b:tag Tag

Dynamically generates an HTML tag. See b:tag guide.

<b:tag expr:name='data:view.isPost ? "h1" : "h2"'>
  <data:post.title/>
</b:tag>

2. The b:attr Tag

Adds an Attribute to the parent tag. Learn more at b:attr documentation.

<div class='my-item'>
  <b:attr name='style' value='color:red'/>
</div>

3. The b:class Tag

A specialized version of b:attr for adding CSS classes. Very useful for responsive layouts. See b:class documentation.

<div class='post'>
  <b:class expr:name='data:view.isHomepage ? "featured" : "normal"' />
</div>

These tags give you surgical precision over your blog's HTML structure, which is vital for Advanced SEO and professional Design.
