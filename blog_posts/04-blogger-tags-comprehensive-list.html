Blogger Tags: Comprehensive List

Blogger tags are special XML tags used to build the structure and logic of a theme. They are easily identified by the b: prefix. Here is a breakdown of the most important tags you will use.

Structural Tags

  • <b:section>: Defines a high-level area of your blog (like Header, Sidebar, Blog Posts). It can only contain b:widget tags.
  • <b:widget>: Represents a specific gadget (like a Search box or Label list).

Logic & Control Flow

  • <b:if>, <b:elseif/>, <b:else/>: Conditional tags used to show or hide content based on specific statements.
  • <b:switch>, <b:case/>, <b:default/>: A more efficient way to handle multiple conditions.
  • <b:loop>: Used to iterate over a list of items (like a list of posts or labels).

Modular Code (Inclusions)

  • <b:includable>: A reusable block of code. Every widget must have one with id='main'.
  • <b:include/>: Calls and executes a b:includable block.

Variables & Data

  • <data:.../>: Displays a specific piece of data (e.g., <data:blog.title/>).
  • <b:with>: Creates a temporary variable or alias for an expression.
  • <b:eval/>: Evaluates and displays the result of a Blogger expression.

Dynamic Elements

  • <b:tag>: Dynamically generates an HTML tag.
  • <b:attr/>: Adds an attribute to its parent tag.
  • <b:class/>: Adds a CSS class to its parent tag.

Other Essential Tags

  • <b:skin>: Where the main CSS for the theme is stored.
  • <b:template-script>: Used for including JavaScript in specific ways.
  • <![CDATA[ ... ]]>: Used to prevent the Blogger compiler from encoding characters like < or & in your scripts and styles.
