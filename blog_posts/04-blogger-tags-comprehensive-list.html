Blogger Tags: Comprehensive List

Blogger tags are special XML tags used to build the structure and logic of a theme. They are easily identified by the b: prefix. For a full reference of every tag, visit Blogger Tag Intro.

Structural Tags

  • <b:section>: Defines a high-level area of your blog. See our Deep Dive into Sections.
  • <b:widget>: Represents a specific gadget. Learn how to add widgets manually.

Logic & Control Flow

  • <b:if>: Basic conditional. See Blogger Conditional Tags.
  • <b:loop>: Iterates over data. See Mastering the b:loop Tag.
  • <b:switch>: Efficient multiple conditions. See Advanced Theme Tags.

Modular Code (Inclusions)

  • <b:includable>: A reusable block of code.
  • <b:include/>: Calls and executes an includable block. This is a key part of modern modular theme design.

Dynamic Elements

  • <data:.../>: Displays Blogger Data.
  • <b:eval/>: Evaluates Blogger Expressions.

These tags form the vocabulary of your theme. By combining them with Attributes and Operators, you can create professional-grade layouts.
