Using Blogger's 'Contact Form' Widget with Custom CSS

A contact form is essential for any professional blog. While Blogger provides a built-in 'Contact Form' gadget, it often doesn't match your theme's CSS styling. Let's fix that.

1. Adding the Widget

Go to Layout > Add a Gadget > Contact Form. By default, it will appear in your sidebar or footer. You can also hide it using CSS (display:none) and only show it on a dedicated 'Contact' page using Conditional Tags.

2. Customizing the Look

The contact form elements have specific IDs like #ContactForm1_contact-form-name. You can target these in your <b:skin> to change colors, fonts, and padding.

.contact-form-name, .contact-form-email, .contact-form-email-message {
  width: 100%;
  padding: 10px;
  margin-bottom: 10px;
  border: 1px solid #ccc;
  border-radius: 4px;
}
.contact-form-button-submit {
  background-color: #007bff;
  color: #fff;
  cursor: pointer;
}

3. Advanced: Moving the Form to a Page

Instead of the sidebar, you might want the form on its own page. You can manually add the HTML gadget to a static page and use the default Blogger CSS classes to ensure the backend functionality still works.

A professional contact form builds trust with your audience and potential sponsors, helping you grow your blog into a business.
