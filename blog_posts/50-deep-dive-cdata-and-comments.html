Deep Dive: CDATA and Comment tags

The CDATA block and <b:comment> tag are essential for managing how your code is processed by the Blogger engine and viewed by search bots. See CDATA and b:comment for more.

1. The CDATA Block

CDATA stands for "Character Data." It tells the XML compiler: "Do not process this section as XML; it's just raw text." This is critical for CSS styling and JavaScript.

<style>
/*<![CDATA[*/
  body { background: url('...&...'); }
/*]]>*/
</style>

Without CDATA, characters like & or < would cause template errors.

2. The b:comment Tag

While standard HTML comments (<!-- -->) are visible in the source code, <b:comment> is only visible in your template editor. It's perfect for documenting your code for other developers or for your future self.

3. Best Practices

Use b:comment to mark different sections of your theme. Use CDATA whenever you are adding custom Widgets that include complex scripts. Both help maintain high performance and clean code.
