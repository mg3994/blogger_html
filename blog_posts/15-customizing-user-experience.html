Customizing UX: 404 Pages, Mobile m=1, and GDPR

A great blog isn't just about content; it's about the user experience. Here is how to handle some common technical hurdles.

1. Creating a Custom 404 Page

When a visitor lands on a broken link, don't let them see a generic error message. Create a custom 404 page that helps them find what they were looking for.

  1. Go to Settings > Errors and redirects > Custom 404.
  2. Enter your custom HTML message. You can include links to your best posts or a search box.

2. Dealing with the ?m=1 Parameter

Blogger adds ?m=1 to URLs when a visitor is on a mobile device. While this helps Blogger serve mobile-optimized versions of old themes, many modern responsive themes don't need it.

To "disable" it (via redirect), you can add a small JavaScript snippet to your theme's <head> that removes the parameter from the URL, keeping your links clean for sharing.

3. GDPR and Cookie Notifications

If you have visitors from the EU, you are required by law to show a cookie consent banner. Blogger provides a default banner automatically for blogs on .blogspot domains.

If you use a Custom Domain, you may need to implement your own notification. You can customize the look of the default Blogger banner using CSS targeting the #cookieChoiceInfo ID.

#cookieChoiceInfo {
  background-color: #333 !important;
  color: #fff !important;
  font-family: 'Arial', sans-serif;
}

Small tweaks to these areas can make your blog feel much more modern and user-friendly.
