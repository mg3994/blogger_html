Deep Dive: b:section and b:widget Tags

The <b:section> and <b:widget> tags are the foundation of any Blogger theme. For more detailed documentation, check the b:section and b:widget guides.

1. The <b:section> Tag

Sections are high-level containers that organize your layout. They can only contain <b:widget> tags. You can use Blogger Tricks to hide these sections on specific pages.

Key Attributes:

  • id (Required): A unique name for the section.
  • maxwidgets: Limits how many gadgets can be added.
  • showaddelement: Controls visibility in the Layout tab.
<b:section id='main-sidebar' class='sidebar' maxwidgets='5' showaddelement='yes'>
  <!-- Widgets go here -->
</b:section>

2. The <b:widget> Tag

Widgets are the actual gadgets that display content. They must reside inside a <b:section>. You can learn how to add custom widgets manually if the default ones aren't enough.

Key Attributes:

  • id (Required): A unique ID (e.g., "Header1").
  • type (Required): The type of widget.
  • locked: If "yes", the widget cannot be deleted.

Widgets rely heavily on <b:includable> tags to define their layout. Learn more in our Blogger Tags overview.
