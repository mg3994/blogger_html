Deep Dive: b:section and b:widget Tags

The <b:section> and <b:widget> tags are the foundation of any Blogger theme. They define the structural layout and the functional components (gadgets).

1. The <b:section> Tag

Sections are high-level containers that organize your layout. They can only contain <b:widget> tags.

Key Attributes:

  • id (Required): A unique name for the section (e.g., "header", "sidebar").
  • class: CSS class for styling.
  • maxwidgets: Limits how many gadgets can be added to this section.
  • showaddelement: If "yes", shows the "Add a Gadget" link in the Layout tab.
<b:section id='main-sidebar' class='sidebar' maxwidgets='5' showaddelement='yes'>
  <!-- Widgets go here -->
</b:section>

2. The <b:widget> Tag

Widgets are the actual gadgets that display content. They must reside inside a <b:section>.

Key Attributes:

  • id (Required): A unique ID (e.g., "Header1", "Blog1").
  • type (Required): The type of widget (e.g., "Header", "Blog", "Label", "HTML").
  • title: The display title of the widget.
  • locked: If "yes", the widget cannot be moved or deleted in the Layout tab.
  • visible: If "no", the widget is hidden.
<b:widget id='Header1' locked='true' title='Blog Header' type='Header' version='2'>
  <b:includable id='main'>
    <h1><data:title/></h1>
  </b:includable>
</b:widget>

Understanding these two tags is the first step in moving from a basic blog user to a theme developer.
