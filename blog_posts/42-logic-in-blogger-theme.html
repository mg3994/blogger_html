Implementing Blogger Logic in blogger_theme

How do you use BIf, BLoop, and Lambda operators inside a Dart framework? blogger_theme makes it incredibly intuitive.

1. Conditionals (BIf)

Instead of the <b:if> XML tag, you use the BIf component:

BIf(
  cond: 'data:view.isPost',
  children: [ Text('You are viewing a post!') ]
)

2. Iteration (BLoop)

Looping through Array data is just as easy:

BLoop(
  values: 'data:posts',
  varName: 'post',
  children: [
    BData(value: 'post.title')
  ]
)

3. Using Blogger Expressions

You can use all your favorite Operators and Advanced Lambda functions directly in the cond or value strings. The framework ensures the final XML output is perfectly formatted for the Blogger engine.

This allows you to keep all your SEO and layout logic in one place, using a clean and consistent syntax.
