Deep Dive: b:includable and b:include (Modular code)

The <b:includable> and <b:include> tags are the keys to writing modular and clean code in Blogger. They allow you to define a block of code once and "include" it wherever you need it. Learn more at BloggerBasics101.

1. The b:includable Tag

This is where you define your code block. It must have a unique id. Every widget must have an includable with id='main'.

<b:includable id='postTitle' var='post'>
  <h2><data:post.title/></h2>
</b:includable>

2. The b:include Tag

This is how you call your defined block. You use the name attribute to match the id of the includable.

<b:include name='postTitle' data='post'/>

3. Why use them?

  • Reusability: Use the same "Post Title" design on your homepage, search pages, and post pages.
  • Readability: Keep your Blog1 widget from becoming a giant, confusing mess of code.
  • Modular Design: This concept is the basis for professional multi-file development.

Mastering inclusions is the first step in moving from simple template editing to building a modern framework-based theme.
