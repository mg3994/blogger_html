Advanced Tags: b:defaultmarkups and b:switch

As you move into advanced theme design, you'll want to use more efficient tags to manage your code. <b:defaultmarkups> and <b:switch> are two powerful tools for professional designers.

1. The b:defaultmarkups Tag

In traditional Blogger themes, if you wanted to change how every "Label" widget looks, you had to edit every single Label widget individually. <b:defaultmarkups> changes that. It allows you to define a "global" design for a widget type.

<b:defaultmarkups>
  <b:defaultmarkup type='Common'>
    <b:includable id='main'>
      <!-- This design will apply to ALL widgets of this type by default -->
      <div class='global-widget-style'>
        <b:include name='content'/>
      </div>
    </b:includable>
  </b:defaultmarkup>
</b:defaultmarkups>

2. The b:switch Tag

When you have many different conditions (e.g., you want different titles for 10 different labels), using multiple <b:if> and <b:elseif/> tags can get messy. <b:switch> is a cleaner alternative.

<b:switch var='data:blog.pageType'>
  <b:case value='item'/>
    <!-- Code for Post Pages -->
  <b:case value='static_page'/>
    <!-- Code for Static Pages -->
  <b:default/>
    <!-- Code for everything else -->
</b:switch>

3. Why use these?

  • Clean Code: Reduces the "spaghetti code" feel of complex templates.
  • Maintainability: Change your design in one place, and it updates everywhere.
  • Efficiency: The Blogger compiler can process switches faster than long chains of if/else statements.

Mastering these tags is what separates a casual "tweaker" from a true Blogger Theme Developer.
