Custom Homepages and Hiding Sidebars

Sometimes you want a specific page or a unique layout to be the first thing people see when they visit your blog, rather than a list of recent posts.

1. Creating a "Real" Homepage

By default, Blogger's homepage is a feed of your latest posts. To create a static landing page:

  1. Create a static Page (not a post) with your landing page content.
  2. Go to Settings > Errors and redirects > Custom redirects.
  3. Redirect from / (your home) to the URL of your new page.

Note: This is a simple way, but a more advanced way is using conditional tags (b:if) in your theme to show unique content only when data:view.isHomepage is true.

2. Hiding Sidebars on Specific Pages

Many designers prefer a "Full Width" look for static pages or specific posts. You can achieve this using Blogger's conditional tags to conditionally hide the sidebar section.

The Code Trick:

In your XML, find the sidebar section and wrap it:

<b:if cond='!data:view.isPage'>
  <b:section id='sidebar'>
    <!-- Sidebar widgets -->
  </b:section>
</b:if>

The ! means "NOT". So this code says: "Show the sidebar ONLY if the current view is NOT a static page."

3. Adjusting Content Width

Don't forget to adjust your main content's width when the sidebar is hidden. You can use a conditional class for this:

<div expr:class='data:view.isPage ? "main-content full-width" : "main-content"'>
  <!-- Post content -->
</div>

These advanced layout tricks allow you to break free from the standard Blogger "Blog" look and create a truly unique website.
