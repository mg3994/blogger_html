Blogger Attribute Introduction

Every Blogger tag (starting with b:) can have one or more attributes. These attributes provide additional information or modify the default behavior of the tag. Understanding how to use these attributes is crucial for creating dynamic and functional templates.

Learn more: See the full Attribute Reference at BloggerBasics101.

Blogger Expressions in Attributes

Attributes in Blogger tags are designed to work with the Blogger Data Types. Their values can be:

  • String: Wrapped in quotes (e.g., "example").
  • Boolean: Written without quotes (e.g., true).
  • Number: Written without quotes (e.g., 123).
  • Object: Written with braces (e.g., { item1: "value" }).
  • Array: Written with square brackets (e.g., ["a", "b"]).
  • Blogger Data: Direct reference to data (e.g., data:blog.title).
  • Blogger Expression Operation: Using Blogger Operators to calculate a value.

Pro Tip: You can convert a standard HTML attribute into a Blogger Expression attribute by adding the expr: prefix (e.g., expr:href="data:blog.url"). This is commonly used in SEO Breadcrumbs.

Common Blogger Attributes

Attribute Applies To Description
cond b:if, b:section, b:widget, etc. A condition that must be true for the tag to execute.
data b:includable, b:include Passes data as an alias to the included content.
id b:section, b:widget, b:includable A unique identifier for the element.
var b:loop, b:with The name of the variable container for the data.
