blogger_theme: Setup and Project Structure

Ready to move beyond raw XML? Let's set up your first project using the blogger_theme Dart library. This is the first step towards hassle-free theme development.

1. Prerequisites

You need to have the Dart SDK installed on your computer. If you are a Flutter developer, you already have it!

2. Initializing your Project

mkdir my_blogger_theme
cd my_blogger_theme
dart pub init

Add the dependency to your pubspec.yaml:

dependencies:
  blogger_theme: ^3.0.0

3. Recommended Structure

To keep your code organized, follow this multi-file approach:

  • lib/main.dart: Theme generation logic.
  • lib/src/components/: Your custom Blogger Widgets.
  • lib/src/styles.dart: Your b:skin variables and CSS.

This structure allows for modular, reusable code, making it easy to build and maintain complex professional themes.
