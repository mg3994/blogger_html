Advanced Operators: Lambda, Resize, and Snippets

Beyond basic math, Blogger offers advanced Operators that give you granular control over your content. For a full list, visit BloggerBasics101.

1. Lambda Operators (=>)

Lambda expressions allow you to perform complex operations on Arrays. Learn more about Lambda Operators here.

<!-- Count how many labels are named "News" -->
<b:eval expr='data:post.labels count (l => l.name == "News")'/>

2. resizeImage Operator

Critical for Performance Optimization. It resizes images hosted on Google/Blogger. See ResizeImage details.

<img expr:src='resizeImage(data:post.featuredImage, 200)'/>

3. snippet Operator

Used to create excerpts for Post Label Summaries. Learn more about Snippet settings.

<b:eval expr='snippet(data:post.body, {length: 150})'/>

Combining these with Conditional Tags allows you to build a truly professional and high-performance blog.
