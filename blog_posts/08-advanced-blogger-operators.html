Advanced Operators: Lambda, Resize, and Snippets

While basic math and logic are great, Blogger offers advanced operators that give you granular control over your content and images.

1. Lambda Operators (=>)

Lambda expressions allow you to perform complex operations on arrays of data without writing multiple loops.

  • filter: Returns only items that match a condition.
  • any: True if at least one item matches.
  • all: True if every item matches.
  • count: Returns the number of items matching a condition.
<!-- Count how many labels are named "News" -->
<b:eval expr='data:post.labels count (l => l.name == "News")'/>

2. resizeImage Operator

This is a lifesaver for performance. It allows you to request a specific size for an image hosted on Google/Blogger.

<!-- Resize post thumbnail to 200px width -->
<img expr:src='resizeImage(data:post.featuredImage, 200)'/>

<!-- Resize to 400px with a specific aspect ratio (square) -->
<img expr:src='resizeImage(data:post.featuredImage, 400, "1:1")'/>

3. snippet Operator

Used to create a summary of a long text block. Great for post excerpts.

<!-- Show first 150 characters of post body, removing HTML tags -->
<p><b:eval expr='snippet(data:post.body, {length: 150, links: false, linebreaks: false})'/>...</p>

4. Ternary Operator (? :)

A compact way to write an if/else statement in a single line.

<!-- Use "Post" if it's a post view, otherwise use "Blog" -->
<b:eval expr='data:view.isPost ? "Post View" : "Blog View"'/>

Mastering these advanced operators will significantly reduce the amount of code in your template while making it much more powerful.
