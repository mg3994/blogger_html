Blogger Conditional Tags: b:if, b:else, and b:elseif

Conditional tags allow you to show or hide content based on specific conditions. This is the secret to creating custom homepages and hiding sidebars. For more examples, see BloggerBasics101's Conditional Guide.

Basic Syntax

<b:if cond='CONDITION'>
  <!-- Content to show if condition is true -->
</b:if>

Commonly Used Conditions

Condition Description
data:view.isHomepage True if on the main homepage. Used for Real Homepages.
data:view.isPost True if viewing a specific blog post. Essential for Breadcrumbs.
data:view.isMobile True if using a mobile device. Useful for Limiting Posts on Mobile.

Conditions work by evaluating Blogger Data using Comparison Operators. For handling many conditions at once, check out the b:switch tag.
