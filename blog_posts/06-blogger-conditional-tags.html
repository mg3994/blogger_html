Blogger Conditional Tags: b:if, b:else, and b:elseif

Conditional tags allow you to show or hide content based on specific conditions, such as which page the visitor is currently viewing.

Basic Syntax

<b:if cond='CONDITION'>
  <!-- Content to show if condition is true -->
</b:if>

Using b:else and b:elseif

<b:if cond='data:view.isPost'>
  <p>This is a post page.</p>
<b:elseif cond='data:view.isPage'/>
  <p>This is a static page.</p>
<b:else/>
  <p>This is something else (Home, Label, or Archive).</p>
</b:if>

Commonly Used Conditions

Condition Description
data:view.isHomepage True if the visitor is on the main homepage.
data:view.isPost True if the visitor is viewing a specific blog post.
data:view.isPage True if the visitor is viewing a static page.
data:view.isLabelSearch True if the visitor is viewing a label result page.
data:view.isMobile True if the visitor is using a mobile device.
data:blog.url == data:blog.homepageUrl Another way to check for the homepage.

These tags are essential for customizing layouts, such as hiding sidebars on post pages or showing unique banners on the homepage.
