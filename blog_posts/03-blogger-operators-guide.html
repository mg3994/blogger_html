Blogger Operators Guide

In programming, an operator is a character that tells the compiler to perform a specific action. Blogger has its own set of operators used within its XML template language. For a deep dive into each category, visit the Blogger Operator Intro.

1. Arithmetic Operators

Used for mathematical calculations within Blogger Attributes:

  • Addition: +
  • Subtraction: -
  • Multiplication: *
  • Division: /
  • Modulo: %

2. Comparison Operators

Used to compare two values, often within b:if conditional statements:

  • Equality: == or eq
  • Inequality: != or neq
  • Less Than: < or lt
  • Greater Than: > or gt

3. Logical Operators

Used to combine multiple Boolean data types:

  • AND: && or and
  • OR: || or or
  • NOT: ! or not

4. Advanced Operators

For more complex logic, including image manipulation and text shortening, see our guide on Advanced Blogger Operators (Lambda, Resize, Snippet).

Mastering these operators allows you to build highly dynamic themes that react to different Data Types and user views.
