Generating and Uploading your XML

The final step of the modern development workflow is turning your Dart code into a real Blogger theme file.

1. The Generate Command

In your main.dart file, you'll call BloggerTheme.generate(). When you run your Dart script, it prints the full XML to your console or saves it to a file.

void main() {
  final theme = BloggerTheme(...);
  print(theme.generate());
}

2. Uploading to Blogger

  1. Go to your Blogger dashboard.
  2. Select Theme.
  3. Click the arrow next to 'Customize' and select Edit HTML.
  4. Delete everything and paste the XML generated by your Dart code.
  5. Click Save.

3. Testing your Theme

Once uploaded, use the Inspect Tool to verify that all your Sections and Widgets are appearing correctly. If you find a bug, simply fix it in your Dart code and regenerate the file. It's truly a hassle-free experience!
