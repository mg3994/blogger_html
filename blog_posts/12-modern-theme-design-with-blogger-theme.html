Introducing Modern Theme Design with blogger_theme

Writing raw Blogger XML can be tedious. But what if you could design your theme using Dart and split it into multiple files? That's exactly what the blogger_theme package allows you to do.

What is blogger_theme?

blogger_theme is a lightweight Dart library for generating Blogger (Blogspot) theme XML using a clean, declarative API inspired by Jaspr and Flutter.

Why use a Framework?

  • Modular Code: Split your theme into components. This is the core of hassle-free development.
  • Type Safety: Catch errors before you ever upload.
  • Modern Workflow: Use tools like VS Code and Git.

Basic Syntax Comparison

Instead of writing raw Blogger Tags, you use Dart classes:

// Dart code using blogger_theme
BIf(
  cond: 'data:view.isPost',
  children: [
    Div(
      attributes: {'class': 'post-body'},
      children: [BData(value: 'post.body')],
    ),
  ],
)
