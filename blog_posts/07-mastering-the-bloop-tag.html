Mastering the b:loop Tag

The <b:loop> tag is used to iterate through a collection of data, such as a list of blog posts, labels, or comments. It is the workhorse of dynamic content display in Blogger.

Basic Syntax

<b:loop values='DATA_COLLECTION' var='VARIABLE_NAME'>
  <!-- Content to repeat for each item -->
</b:loop>

Example: Listing Labels

<ul>
  <b:loop values='data:posts.first.labels' var='label'>
    <li><a expr:href='data:label.url'><data:label.name/></a></li>
  </b:loop>
</ul>

Advanced Attributes

  • index: A variable name to track the current position in the loop (starting at 0).
  • reverse: If set to "true", the loop iterates in reverse order.
<b:loop values='data:posts' var='post' index='i'>
  <p>Post Number <data:i/>: <data:post.title/></p>
</b:loop>

Filtering Loops

You can combine loops with lambda operators for powerful results:

<!-- Only show the first 3 posts -->
<b:loop values='data:posts limit 3' var='post'>
  <h2><data:post.title/></h2>
</b:loop>

Loops allow you to create beautiful, data-driven grids and lists that update automatically as you publish new content.
