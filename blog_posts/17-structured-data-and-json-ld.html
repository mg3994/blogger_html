Structured Data and JSON-LD for Blogger

Structured data is a standardized format for providing information about a page and classifying the page content. It helps search engines understand the context of your posts and display "rich snippets" in search results.

1. What is JSON-LD?

JSON-LD (JavaScript Object Notation for Linked Data) is the recommended format by Google for implementing structured data. It's a block of code that tells Google: "This is an article," "This is a product," or "This is a recipe."

2. Why is it important?

Blogs with valid structured data can get enhanced search results, such as:

  • Star ratings.
  • Image thumbnails next to the search result.
  • Author information.
  • Publishing date.

3. Implementing Article Schema in Blogger

You can add a JSON-LD block to your theme's <head> section using Blogger data tags to fill in the values dynamically.

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BlogPosting",
  "mainEntityOfPage": {
    "@type": "WebPage",
    "@id": "<data:blog.url.canonical.jsonEscaped/>"
  },
  "headline": "<data:view.title.jsonEscaped/>",
  "description": "<data:view.description.jsonEscaped/>",
  "image": "<data:view.featuredImage.jsonEscaped/>",
  "author": {
    "@type": "Person",
    "name": "<data:post.author.name.jsonEscaped/>"
  },
  "publisher": {
    "@type": "Organization",
    "name": "Blogger",
    "logo": {
      "@type": "ImageObject",
      "url": "URL_TO_YOUR_LOGO"
    }
  },
  "datePublished": "<data:post.timestamp.iso8601.jsonEscaped/>"
}
</script>

Note: Always use the .jsonEscaped modifier to ensure that quotes or special characters in your titles don't break the JSON code.

By using JSON-LD, you are speaking the same language as search engine bots, making your content much easier for them to process and rank.
