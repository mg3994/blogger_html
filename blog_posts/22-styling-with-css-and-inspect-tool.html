How to Style your Blogger Theme with CSS and Inspect Tool

You don't need to be a professional coder to change the color of your header or the font of your posts. All you need is a basic understanding of CSS and your browser's "Inspect" tool.

1. Using the Inspect Tool

Right-click on any element on your blog (e.g., your post title) and select Inspect (or press F12). This opens the developer tools.

  • Elements tab: Shows the HTML structure.
  • Styles tab: Shows the CSS currently being applied.

You can live-edit colors and sizes in the Styles tab to see how they look before making any permanent changes.

2. Finding the Right Selector

Look for the class or id of the element you want to change. For example, if your post titles have class="post-title", your CSS will look like this:

.post-title {
  color: #ff5733;
  font-family: 'Roboto', sans-serif;
  font-size: 32px;
}

3. Where to Add your CSS

In Blogger, you have three options:

  1. Advanced Designer: Go to Theme > Customize > Advanced > Add CSS. This is the safest way for beginners.
  2. The b:skin tag: Edit the HTML and find <b:skin>. Paste your code inside the CDATA block.
  3. Style tags: You can also add <style> ... </style> tags directly into your post HTML for post-specific styling.

Pro Tip: Always use !important sparingly. If your CSS isn't applying, it might be because Blogger's default styles are overriding yours.
