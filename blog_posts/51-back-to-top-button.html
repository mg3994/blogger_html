Blogger Trick: "Back to Top" Button without jQuery

A "Back to Top" button improves User Experience, especially on long Post Pages. Most tutorials use heavy jQuery libraries, but you can build a lightweight version with pure JavaScript and CSS.

1. The HTML

Add this just before the </body> tag in your Blogger Theme HTML.

<button id="topBtn" title="Go to top">Top</button>

2. The CSS

Add this to your b:skin or Style section.

#topBtn {
  display: none; position: fixed; bottom: 20px; right: 30px; z-index: 99;
  background-color: #555; color: white; cursor: pointer; padding: 15px;
  border-radius: 10px;
}
#topBtn:hover { background-color: #333; }

3. The JavaScript

window.onscroll = function() {scrollFunction()};
function scrollFunction() {
  if (document.body.scrollTop > 20 || document.documentElement.scrollTop > 20) {
    document.getElementById("topBtn").style.display = "block";
  } else {
    document.getElementById("topBtn").style.display = "none";
  }
}
document.getElementById("topBtn").onclick = function() {
  window.scrollTo({top: 0, behavior: 'smooth'});
}

This lightweight approach maintains high performance while adding a professional touch to your blog.
