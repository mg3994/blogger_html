Creating Post Label Summary Like Google Search Results

By default, Blogger's label pages show full posts or large snippets. You can customize your theme to show a clean, list-based summary that mimics the look of Google Search result snippets.

1. The Goal

Instead of showing long posts, we want to show:

  • The Post Title (linked).
  • A short, clean text snippet (no images or HTML).
  • The date or labels.

2. The Logic

You need to locate the Blog1 widget in your XML and find where the post content is being called. Use a conditional tag to show the summary view only on search and label pages.

<b:if cond='data:view.isSearch or data:view.isLabelSearch'>
  <div class='search-result-item'>
    <h3><a expr:href='data:post.url'><data:post.title/></a></h3>
    <p><b:eval expr='snippet(data:post.body, {length: 160})'/></p>
    <span class='result-url'><data:post.url/></span>
  </div>
<b:else/>
  <!-- Show normal post view -->
  <data:post.body/>
</b:if>

3. Styling for that "Search Engine" Look

.search-result-item h3 {
  color: #1a0dab;
  font-size: 18px;
  margin-bottom: 2px;
}
.search-result-item p {
  color: #4d5156;
  font-size: 14px;
  line-height: 1.5;
}
.result-url {
  color: #006621;
  font-size: 12px;
}

This simple change makes your blog much easier to navigate when users are searching for specific topics.
