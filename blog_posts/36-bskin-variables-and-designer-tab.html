Mastering b:skin Variables and Group Tags

Blogger's 'Theme Designer' (Customize tab) is a powerful way for users to change colors and fonts without touching code. As a designer, you can enable this by using Variable and Group tags inside your Blogger Skin.

1. Defining Variables

Variables allow you to create "placeholders" for CSS values. For example, to let users change the main theme color:

<Variable name="main.color" description="Theme Color" type="color" default="#007bff" value="#007bff"/>

2. Using Group Tags

Groups organize these variables into sections (like 'Background' or 'Links') in the Theme Designer UI.

<Group description="Colors">
  <Variable name="link.color" ... />
</Group>

3. Applying in CSS

Once defined, you use the variable in your CSS styling using the $(variable.name) syntax:

a { color: $(link.color); }

This approach makes your theme extremely user-friendly and professional. If you are building complex themes with many variables, using a modular framework like blogger_theme can help you manage these definitions much more efficiently.
